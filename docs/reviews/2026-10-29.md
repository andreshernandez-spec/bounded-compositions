### R1 — P1: Validate region metadata against its domain

Status: open. [region.cpp](../../src/region.cpp), `describe`;
[sequence.cpp](../../src/sequence.cpp), `make_coordinate`.

A region caches its prefix/subtree flag without domain identity. `describe`
writes `prefix.size()` values into an array of `s.parts()` values before
checking the prefix. Passing the whole region of a fixed four-part space to
a two-part space produces an ASan-confirmed heap-buffer overflow.

Even compatible dimensions and rank bounds do not guarantee valid metadata:

```python
import bounded_compositions as bc

a = bc.Space(1, [0] * 3, [1] * 3)
b = bc.Space(2, [0] * 3, [2] * 3)
r = bc.subtree(a, [1])  # ranks [2, 3)
x = bc.coordinate_sequence(b, r).points(0, 1)[0]
assert b.rank(x) == 3  # outside the requested interval
```

Check a retained domain association at every consumer, or reconstruct cached
metadata from `interval(s, begin, end)` under an explicit transferable-interval
contract. Validate before using prefix lengths or values.

### R2 — P1: Clean up partially constructed thread pools

Status: open. [executor.cpp](../../src/executor.cpp), `thread_pool` constructor.

If a later worker's creation throws, earlier workers remain live while
unwinding destroys synchronization objects and joinable threads. Interposing
`pthread_create` to return `EAGAIN` on its second call reproduced termination
and a hang, depending on scheduling. Stop, notify and join started workers
before unwinding; add failure injection, including the Python pool path.

### R3 — P2: Preserve equivalence of subspace metadata and its table

Status: open. [space.cpp](../../src/space.cpp), `subspace` and `shift_limit`;
[core.cpp](../../python/src/core.cpp), pickle state.

The remaining total is narrowed to int32 unchecked. The fixed composition
`[-2147483648, 2147483647, 2147483647]` has original total `2147483646`.
Fixing its first part produces a subspace reporting total `-2` but returning
`[2147483647, 2147483647]`. Pickling reconstructs an empty space.

Group-limit saturation breaks reconstruction even when the remaining total fits:

```python
import pickle
import bounded_compositions as bc

x = [-2000000000, 1300000000, 1300000000, -2000000000]
s = bc.Space(-1400000000, x, x, groups=[
    bc.Group([0, 1, 2], min_sum=600000000, max_sum=600000000)
])
sub = s.subspace([-2000000000])
assert sub.total == 600000000
assert sub.groups[0].max_sum == 2147483646  # should describe sum 2600000000
assert sub.size == 1
assert pickle.loads(pickle.dumps(sub)).size == 0
```

Preserve wide aggregates, serialize parent plus prefix, or reject unrepresentable
subspaces explicitly. Clipping must not silently change the feasible set.

### R4 — P2: Stabilize repair's cost comparisons

Status: open. [repair.cpp](../../src/repair.cpp), state and plain repair.

For `Space(2, [0,0], [2,2])` and `z=[1e12,1e12]`, repair returns `[1,1]`.
Adding nonbinding `Group([0,1])` changes the answer to `[0,2]`, whose exact
squared distance is larger by two. Squared costs include a large common
offset and lose the difference. At `1e200`, overflow causes `lost the least
cost`; plain repair also loses marginal differences at sufficiently large
magnitudes. Remove common offsets, define numerical accuracy, and test that
redundant constraints preserve the answer.

### R5 — P2: Do not reject a reachable codec cell

Status: fixed. [codec.cpp](../../src/codec.cpp), exact `encode`.

The encoder rounds a cell's center upward on the 64-bit grid, then rejects
the cell if that candidate misses, without checking for another valid code:

```python
import numpy as np
import bounded_compositions as bc

s = bc.Space(99, [0] * 100, [99] + [1] * 99)
x = bc.decode(s, np.zeros(99))  # reachable [0, 1, ..., 1]
bc.encode(s, x, dtype="uint64")  # raises ValueError; zero is a valid code
bc.encode(s, x)                 # also raises
```

Check the representable interval before rejection. Correct codec and adapter
claims that all such narrow cells are unreachable; the architecture guide
records the distinction now.

Resolution: when the centre misses, the 64-bit encoder takes the middle of the
codes that decode into the cell, and the double encoder the smallest double at
or above the cell's first code; both throw only when no code of their type
decodes to x. The double encoder checks each part's code against its cell
instead of decoding the whole composition again. `codec.hpp`, the Python
`encode` docstring and the SciPy adapter's notes say so. Regression tests:
"every composition decode produces has a code" (decodes edge and random codes
on spaces whose first and last cells are narrower than 2^-64, then encodes
the results) and `test_narrow_cells_that_decode_reaches_have_codes`.

### R7 — P2: Implement the nearest-double conversion contract

Status: fixed. [natural.cpp](../../src/natural.cpp), `to_double`.

For little-endian limbs `{1, 2^53 + 1}`, integer
`166153499473114502559719956244594689`, conversion returns `0x1p+117`.
The nearest double is `0x1.0000000000001p+117`. Rounding the highest limb
before incorporating lower limbs causes double rounding. Round once using
remaining-bit information and test halfway values and immediate neighbors.
The current closeness test is weaker than the public contract.

Resolution: `to_double` takes the top 64 bits, sets the last one if any lower
bit is set, and converts once. Regression test: "natural to_double is the
nearest double with ties to even" (the counterexample, ties and both
neighbours across limb boundaries, and the overflow tie at 2^1024).

### R8 — P2: Widen group-range operands before arithmetic

Status: open. [space.cpp](../../src/space.cpp), `set_groups`.

`std::min<int64_t>(lo, shifted_total + 1)` adds in int32 before widening.
A one-part space with total/upper bound `INT32_MAX`, lower bound zero and
group `{0}` triggers UBSan before the table-size guard rejects the request.
Widen first and check dimensions before narrowing.

### R9 — P2: Require actual Meson test coverage

Status: open. [meson.build](../../meson.build), [CI](../../.github/workflows/ci.yml).

Both Catch2 lookups are optional; every Meson test, including fuzz smoke,
depends on Catch2 being found. CI installs Meson/Ninja without ensuring Catch2
is available. If absent, the job can succeed with no tests. Meson also omits
the kernel checker and standalone headers. This follows the source configuration;
hosted CI state was not inspected. Require test dependencies/nonempty registration
in CI and include kernel guards or a separate mandatory verification path.

### R10 — P2: Instrument the compiled host for guided fuzzing

Status: open. [tests/CMakeLists.txt](../../tests/CMakeLists.txt) and CI.

The harness gets `-fsanitize=fuzzer,address,undefined`; the compiled library
gets only CI's address/undefined flags. Fuzz objects confirm `space.cpp.o`
has no sanitizer coverage hooks while the harness does, limiting coverage
guidance. Instrument a dedicated fuzz library with coverage, for example
`-fsanitize=fuzzer-no-link,address,undefined`, and link the runtime at the executable.

## Names and organization

Retain the coherent core vocabulary and short mathematical locals with clear
scope/formulas. Clarify original/shifted totals, table/rank widths and segment/
group metadata; use named flags or accessors around flat tuples. Preserve the
host/kernel/binding/adapter separation and split modules by responsibility.
Align sources/tests between CMake, reduced-limb builds and Meson. Public
contracts need buffers, lifetimes, reentrancy and state changes on failure.

Constrained `space::next` also allocates scratch inside `noexcept`, so allocation
failure terminates; audit this against the new resource policy.
